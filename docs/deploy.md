# Deploying RidesRus

A public demo needs three things: the API with Postgres, and three static front ends.

## 1. API + Postgres on Render

`render.yaml` at the repo root is a Render Blueprint. It creates:
- a managed Postgres instance;
- a Docker web service built from `apps/api/Dockerfile`, which runs migrations and the idempotent seed on every boot.

Steps:
1. In Render choose **New → Blueprint** and select this repository.
2. Set `SEED_ADMIN_PASSWORD` to something private. The public demo password is only used when this is unset.
3. Once the front ends exist (step 2), set:
   - `PUBLIC_API_URL`: the API's URL.
   - `CORS_ORIGINS`: the three front-end URLs, comma-separated.

`JWT_SECRET` and `QR_SECRET` are generated by Render. Free-tier services sleep when idle, so the first request after a nap takes about 30 seconds.

Any Postgres works, including Neon, Supabase and RDS. Set `DATABASE_URL`, and set `DATABASE_SSL=true` if the provider needs TLS.

## 2. Front ends on Netlify

Each app has its own `netlify.toml`. Create **three Netlify sites** from this repo:

| Site | Package directory | Environment variable |
| --- | --- | --- |
| Passenger | `apps/passenger` | `EXPO_PUBLIC_API_URL=https://<api>` |
| Driver console | `apps/driver` | `EXPO_PUBLIC_API_URL=https://<api>` |
| Fleet HQ | `apps/admin` | `NEXT_PUBLIC_API_URL=https://<api>` |

For all three, keep the base directory as the repo root so npm workspaces resolve `@ridesrus/core`.

Optional: set `EXPO_PUBLIC_MAP_TILES_URL` or `NEXT_PUBLIC_MAP_TILES_URL` to a commercial tile provider. OpenStreetMap's public tiles are fine for a demo, but their usage policy forbids heavy production traffic.

## 3. Going from demo to pilot

| Setting | Demo | Pilot |
| --- | --- | --- |
| `DEMO_MODE` | `true` | `false`: no autopilot, guest accounts, simulate-scan or welcome credit |
| `PAYMENTS_PROVIDER` | `sandbox` | `flutterwave`, plus `FLW_SECRET_KEY` and `FLW_WEBHOOK_HASH` |
| Flutterwave dashboard | — | Webhook URL `https://<api>/payments/flutterwave/webhook` with the same secret hash |
| `FLW_REDIRECT_URL` | — | `ridesrus://wallet`, or the passenger web URL |
| Mobile apps | web builds | `eas build` for the passenger app (store) and the driver console (Android APK, kiosk/screen-pinned) |
| Android maps | — | `GOOGLE_MAPS_ANDROID_KEY` for `react-native-maps` |

The API refuses to boot in production with sandbox payments unless demo mode is on.
